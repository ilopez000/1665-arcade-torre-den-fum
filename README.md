# La Torre d'en Fum · Arcade del RA2 (MP 1665)

Videojoc arcade en un sol fitxer HTML per treballar els apartats 3 a 8 de la teoria del RA2 (tecnologies habilitadores digitals) i els errors típics de l'apartat 10. Complementa el RPG «Els Segells de Vilabit» i el simulador «Empresa 4.0».

## Com es fa servir
Juga a la web pública: https://1665-arcade-torre-den-fum.pages.dev

També es pot obrir `index.html` directament amb el navegador (cal Internet per a les fonts i el generador de PDF). L'alumne escriu el nom i el grup i puja les vuit plantes. En guanyar el duel final, el botó «Descarrega l'informe PDF» li baixa els resultats; també el pot descarregar en qualsevol moment des de la torre.

## Regles
- Cada planta té tres onades cada cop més ràpides i 3 vides per onada.
- Compta l'encert a la primera del primer intent complet de cada planta; és la nota de l'informe.
- Cal un 70% per obrir la planta següent. Es poden repetir plantes per guanyar estrelles.
- Cada errada mostra la resposta correcta i el perquè, i la pregunta torna a sortir.
- La partida es desa al navegador.

## Informe PDF
Nom, grup, data, temps de joc, nota global /100 (mitjana dels primers intents), taula per planta amb CA, primer intent, millor intent, estrelles i nivell, apartat «Per repassar» amb cada errada explicada i codi de verificació.
